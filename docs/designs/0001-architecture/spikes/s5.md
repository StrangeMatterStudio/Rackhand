# Spike S5: Claude Code headless (plan T13)

**Question.** Which flags run Claude Code headless with one stdio MCP server and nothing else (no built-in tools, no
user or project MCP servers), emit stream-json, and stop cleanly at a deadline, from a configuration directory that
holds only the provider credential?

**Method.** `spikes/s5/run.sh` (deleted after the run): a stub stdio MCP server with two tools (`echo`, `slow`) that
records which configured servers start; a user-level decoy server in the configuration directory and a project
`.mcp.json` decoy in the working directory; a control run without the restricting flags, a restricted run asked to
call `echo` and to run a shell command, and a run killed with SIGTERM 20 s into a 120 s tool call. The configuration
directory is a fresh one holding only a copy of the owner's `.credentials.json`.

**Finding.** The flags below do it. `--strict-mcp-config` is required: without it a `-p` run starts the user-level
servers and the working directory's `.mcp.json` servers too (the control run started both decoys). `--tools ""`
removes every built-in tool, so the run's tool list is exactly the stub's; asked to run a shell command it had no tool
for it. stream-json needs `--verbose` with `-p`; every line parsed. SIGTERM to `claude` ends it and its MCP server
child within 5 s. The directory needs only `.credentials.json`; the run adds its own state files (`.claude.json`,
`projects/`, `sessions/` and caches), so the operator's directory is the runner's alone.


Run 2026-11-21T02:35Z with 2.1.328 (Claude Code) in WSL Ubuntu.

## Flags

```
claude -p --mcp-config <work>/stub.json --strict-mcp-config --tools "" --allowedTools mcp__stub__echo,mcp__stub__slow --output-format stream-json --verbose --max-turns 4 --no-session-persistence --permission-mode dontAsk <prompt>
```

with `CLAUDE_CONFIG_DIR` set to a directory that holds only `.credentials.json` (and the `.claude.json` the
run writes).
