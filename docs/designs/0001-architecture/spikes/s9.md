# Spike S9: TrueNAS API (plan T14)

**Question.** Which API do current TrueNAS releases support for the driver's reads (pool health and use, disk
temperatures, SMART status, alerts): REST or JSON-RPC over WebSocket? And recorded responses for the AC11 simulator.

**Method.** `spikes/s9/run.sh` (deleted after the run) with an API key the owner created, from the environment only:
`GET` calls on REST `/api/v2.0` and the same reads as JSON-RPC 2.0 calls over the WebSocket at `/api/current`
(`auth.login_with_api_key`, `pool.query`, `disk.query`, `disk.temperatures`, `smart.test.results`, `alert.list`).
Responses are recorded with serials, ids, pool and device names, partition UUIDs, addresses and alert text replaced
with invented values, and checked: no address outside the documentation ranges, no original serial or pool name.

**Finding.** On TrueNAS 25.04 both APIs answer every read. TrueNAS deprecates the REST API from 25.04 in favour of
JSON-RPC over WebSocket, so the driver uses JSON-RPC at `/api/current` and falls back to REST `/api/v2.0` only for a
release without it. Pool health is `healthy` and `status`; use is `size`, `allocated` and `free`; temperatures come
from `disk.temperatures` by disk name; SMART status from `smart.test.results`; alerts from `alert.list` (`level`,
`klass`, `dismissed`). The recorded responses are the AC11 simulator's data
(`crates/rackhand-drivers/tests/fixtures/truenas/`).
