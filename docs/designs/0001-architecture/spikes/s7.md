# Spike S7: git mirror library

**Question (design 17, S7):** push the library mirror over SSH with a deploy key in pure Rust (`gix`) or with
libgit2 (`git2`, statically linked)?

**Answer:** `git2` 0.21 with `ssh`, `vendored-libgit2` and `vendored-openssl`. `gix` 0.90 can't push.

## Method

- `gix` 0.90.0 and `gix-protocol` 0.68.0 sources were searched for a push or `receive-pack` client: there is none, so
  `gix` can only fetch.
- With `git2`, a small program committed a tree (`runbooks/restart-service.yaml`) to a fresh repository and pushed
  `refs/heads/main` over SSH to a bare repository in an Alpine `sshd` container. The deploy key was a new Ed25519 key in
  OpenSSH format, read once and passed to `Cred::ssh_key_from_memory`. The server ran `git-shell` and had
  `receive.denyNonFastForwards = true`.
- It then changed the file, committed on top and pushed again. Finally, it pushed an unrelated history to test refusal
  of a non-fast-forward update.
- The same program was built for `x86_64-unknown-linux-musl` (opt-level z, LTO, abort on panic, stripped) and pushed
  again from the static binary; a baseline without `git2` gives the size cost.

## Results

| Check | Result |
| --- | --- |
| First push (glibc build) | pushed |
| Second push after a change | pushed; the server log shows both commits in order |
| Non-fast-forward push | refused before sending: `NotFastForward` ("contains commits that are not present locally"), reported as an error the caller can turn into a mirror warning |
| Static musl build | `static-pie linked`, 6.14 MB; the same push works from it |
| Size cost | 6.14 MB with `git2` against 0.38 MB without, about 5.8 MB (libgit2, libssh2 and OpenSSL, vendored) |
| Licenses | `git2` and `libgit2-sys` are MIT OR Apache-2.0; libgit2 is GPL-2.0 with a linking exception that allows static linking into non-GPL programs; libssh2 is BSD-3-Clause; OpenSSL 3 is Apache-2.0. All compatible with distributing the hub under MIT OR Apache-2.0 |

## Consequences

- Design 5.3 names `git2` for the git mirror (hub only; the probe doesn't link it).
- The hub binary grows by about 6 MB. That's within the hub's budget (5.2 sets size budgets only for the probe).
- T56 (library and git mirror) uses `git2` with an in-memory key and treats a refused push as a mirror warning, never a
  force push.
